# 工作树侧栏 · 设计契约

仅设计侧栏；所有目录、会话、GIT 数量、主机和更新进度为明确标注的示例。唯一入口是本目录 Canvas，不复制宿主完整 Sidebar，不嵌入截图，不交付独立网页或第二套侧栏实现；验收可用临时工具挂载同一 Canvas 源码，检查结束后清理。

- 信息顺序：顶部唯一任务入口 → 中部项目 / 工作树 / 会话 → 底部设置、通知、更新。侧栏填满画板高度，中部独立滚动。
- 组件边界：对象列表使用 `ItemGroup → li → Item asChild → button`，包括顶部任务和空态最近。Item 提供基础字体、圆角、边框和焦点；普通行 hover 映射宿主 list-hover-bg（Item 默认 muted 与侧栏底色相同，实测无法区分）；底部工具动作独立使用 `Button variant="ghost"`：带文字的设置和下载中状态使用默认 tone，纯图标通知与非下载中更新使用 muted tone / icon 尺寸，不把两种组件皮肤叠在同一行。
- 紧凑布局：公开 Item 尚无桌面单行尺寸，本稿用 `h-7 py-0` 明确约束 28px 行高。这是 Canvas 的紧凑布局适配，不能声称 Item 已提供共享密度变体。Item 原生圆角在该行高下形成胶囊，不另造圆角规则。
- 几何：16px 图标槽、6px 槽间距、16px 尾部状态槽（不超过 280px 时工作树槽间距 4px、层级步进 8px）。工作树缩进由 `--sv-inset` 与 `--sv-step` 单一来源递进；相邻行间隔 2px，工作树组间隔 8px。项目加号使用项目 `icon-xs`：24px 悬停外观、14px 图标；透明命中扩展用 `inset: -2px` 得到 28px 点击范围，hover / focus-within 显现，不缩小行高。顶部三个窗框圆点是侧栏独占画板的窗口按钮示意，`aria-hidden`，不进 Tab。
- 层级与归属：工作树与会话组成一个语义嵌套组。会话列表自身内缩，命中区域、hover、选中一起收窄；不是只缩进文字。子列表起点对齐父身份图标轴，使用 1px `sidebar-border` 中性引导线，7px 内间距加 1px 边线组成 8px 槽位。窄/宽栏子按钮比父按钮真实内缩 32 / 36px；普通目录没有项目父级，内缩 24px。空列表没有导线或额外高度。沿用项目 SidebarMenuSub 的嵌套布局思路，但 Canvas 只组合公开 ItemGroup，不导入私有 Sidebar；不加整组卡片或新色。工作树切换与会话定位仍为两个独立点击目标。
- 名称优先：主目录 Badge 保持完整；非主目录在不超过 280px 时使用文件数摘要，224px 时隐藏行内摘要；320px 保留增删摘要。响应依据可用宽度，不按名称字符数猜测。行内数字仍是可见值。只有工作树行有 HoverCard。项目行、会话行、任务行没有悬停提示。短 Tooltip 只给没有可见文字的纯图标：收起侧栏、打开项目、项目加号、通知、以及非下载中的更新。下载中按钮已有进度数字，设置按钮已有「设置」文字，不再套 Tooltip。不把可见标签或键盘说明再写进 Tooltip。展开侧栏里的短提示不朝工作区右侧展开；`side="right"` 只属于收起成图标轨的名称提示。顶栏收起按钮贴着窗框，提示朝下；其余短提示朝上。卡片只补行上看不到的事实：完整路径、分支（引用 tile 状态栏拥有的分支，行上不画）、有则展示 GIT 增删、远程主机或本机目录。没有变更摘要就不画那一行。不重复叶子名、主目录 Badge 和「需要你处理」。增删数字用产品摘要同款 `text-success` / `text-status-danger-fg` 与 Unicode 减号，不自造色。不把「示例数据」当字段，控件名称也不加这四个字。`w-64 p-3`，延迟 400ms；焦点可打开；Esc 先关卡片。画板右侧用强制打开的同一套 HoverCard 摊开工作树场景标本。
- 状态：仅完成未查看名称加粗，并把未读写进控件 `aria-label`；状态点只作视觉，`aria-hidden`。需要你处理只用状态点的 warning 色，不给整行铺警告底、不改标题和品牌图标颜色。本窗定位用 list-active 背景加 `aria-current`。跨窗行可见文字用「其他窗口」，完整窗口名只进控件名称，不另做 Tooltip。选中工作树与本窗会话使用既有 list-active 背景。任务与工作树/本窗会话互斥：点任务清空树选中与定位；点树或本窗会话清空任务。同一时刻只有一个 `aria-current`（任务 page / 本窗会话 page / 无定位时的工作树 location）。跨窗会话用 `data-elsewhere` 与 `--ring` 描边，不改本窗选中。树与会话分别表达上下文和当前定位，不重复画一份待办列表。通知空态说应用消息，不占用「需要你处理」。
- 交互：工作树点击清除旧会话定位；本窗会话更新工作树与当前会话并消除该会话示例未读；跨窗会话更新反馈但保持本窗选择；若当时在任务上，恢复上次工作树，避免没有当前。项目折叠不导航，播报收起或展开。日常场景默认收起没有等待会话的项目（harbor），把扫描压在当前工作树上。上下 / Home / End 在侧栏可见行移动，含任务与空态最近，根是 `.sv4` 不是只滚动区。Esc 只在 `data-nav` 行上退出任务或取消定位，不从页脚抢浮层。Option+↓ 跳到下一条需要你处理的会话；若该会话所在项目已收起则先展开再聚焦。可见行带同一套 `aria-keyshortcuts`。侧栏只保留一处 live status；读取中/失败经该入口播报。左右键折叠项目。键盘说明只放在侧栏 `aria-describedby`，不进悬停提示。项目行名称含聚合状态。更新「可下载」触发器用「有可用更新」。读取失败使用独立说明，不复用首次打开空态。重试保留播报并聚焦主工作树。滚动条不覆盖产品滑块。设置在窄栏允许收缩。
- 反馈：设置、选择、定位、更新阶段共用反馈入口；旧反馈被替换。只保留侧栏内部一处 live status，画板旁的可见反馈不重复播报。
- 底部：左侧常驻「齿轮 + 设置」文字按钮，右侧常驻通知；条件更新放在通知左侧、间距 6px。DOM / Tab 顺序一致为设置 → 条件更新 → 通知；设置的末端自动留白把通知锚定到右侧，无更新不留按钮空槽。底部水平 inset 与侧栏统一为 8px；设置按钮仅水平内边距紧凑至 8px，保持公开 Button 的 28px 高度、字体和胶囊外观，给窄栏英文与下载进度留足空间。用留白分区，不画分割线。通知使用公开 Popover / Empty；下载示例用 42% 与状态文字，关闭浮层后保留；下载完成后显示重启图标，表示待安装，不表示已经安装。公开 Progress 声明缺失 value 的问题未在本稿修 SDK，不再用展开对象绕过类型，也不仿写进度条。
- 更新显示条件：与当前项目 `appUpdateNeedsAttention` 一致，只在 available / downloading / downloaded 显示；未检测、禁用、空闲、检查中、无新版本、错误均不保留下载入口。画板「无更新」统一预览这些隐藏态的几何，不伪造实际检查结果。正式产品手动检查经设置 → 应用更新；本 Canvas 的设置与更新操作仍为已标注的预览。
- 素材：项目只用折叠箭头，工作树用身份色块，智能体用品牌图标，普通终端用 Lucide SquareTerminal。Button 内图标使用 data-icon，尺寸由原语提供。六个同时出现的示例工作树不重复占用身份槽。
- 评审入口：唯一「画板选项」浮层提供六场景（日常、首次打开、读取中、读取失败、远程主机、非 GIT 目录）、四语言、224 / 256 / 320px 宽度、560 / 800px 高度，以及无更新 / 可下载 / 下载中 / 待重启四个更新状态。默认无更新。读取中只用文字、不用转圈；读取失败给出重试并回到日常。更新状态由画板统一持有，浮层中的阶段演示同步回选项；切换更新状态不重置工作树选择。场景切换保留实例；从最近项目打开后恢复展开、聚焦工作树并保留唯一播报。切换语言才重置示例状态，避免保留上一种语言的播报。画板标题、侧栏、悬停卡片标本、反馈采用正常流，不用多个绝对坐标猜测高度。工作树标本覆盖：主目录+需要处理+增删+main、空闲+未查看+增删+特性分支、运行中+仅文件数、主目录+运行中、空闲+无摘要+无会话、本机目录（无分支）、远程+主机+分支。会话行无悬停卡片。

非 GIT 目录只在对应场景显示「本机目录」，表示有已打开视图的普通目录；它不是所有本机文件夹的集合。

安装宿主缺少 `--identity-1…6` 时，仅身份色块使用 `identity-palette.generated.json` 的对应主题值。该文件是从 `src/renderer/app/globals.css` 提取的两主题各六条声明，记录来源和 token 内容摘要；它是旧宿主设计预览的兼容资产，禁止手动调色或扩展为普通 UI 配色。宿主身份令牌始终优先，Canvas 不重定义全局 `--identity-*`，不使用状态色代替身份色，也不加载整份产品 CSS。

颜色所有者仍是 `globals.css`。当其中 identity 声明改变时，须重新提取兼容资产并逐项验证 12 个值及 `sourceTokenDigest`，不得独立维护另一套配色。此兼容范围只适用于本设计稿的色块，不构成产品业务代码新增颜色值的通用例外。

颜色对比补充：侧栏文字使用 `sidebar-foreground`。GIT 增删与产品 `GitChangeSummaryInline` 同款：插入 `text-success` / `--success`，删除 `text-status-danger-fg`；文件数仍走侧栏前景。次要信息靠字号和位置分层。工作树身份与活动状态继续使用专属语义色。带文字的设置和下载中按钮使用公共 Button 默认 tone，纯图标控件使用 muted tone，颜色由组件拥有，不对标签后代补色。没有新增颜色原值、手工主题分支或全局令牌。空闲点保留完整的 neutral 色；运行点复用更新指示点已有的 2px sidebar 底衬，在 hover 和选中时也保持对比。这是状态图形的对比承托，不是焦点环或第二个状态。身份色与名称是冗余编码，色块本身不代替文字。

实际检查与未完成项目见 [VERIFICATION.md](VERIFICATION.md)。本设计不证明真实工作树整体切换、终端与布局保存或跨窗生产接线已实现。
