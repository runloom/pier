## 1 问题

`apps/mobile-web` 已经把闭环七面跑通，但触感是桌面页塞进手机：点下去没有按下底、主机行要去点小「进入」、hash 整页瞬切、色阶手写 `neutral` / `emerald`，变更入口还会去电脑上抢审查焦点。这不是「还没接上 Ionic」，是视觉和触控语言还没立项——原方案 §11 明确把它们留到另文。

## 2 不换移动端框架

**不引入 Ionic、Framework7、Vant、React Native / Expo。** 理由：

| 选项 | 为什么不做 |
|---|---|
| Ionic / Framework7 | 自带 Material / iOS 皮，会盖掉 Pier 语义令牌；Web Component 阴影树和 Tailwind 打架 |
| 各家 H5 组件库 | 再造一套按钮/列表，和桌面 `packages/ui` 分裂 |
| 现在重写成 RN | 首壳是 Web PWA；原生是薄壳增强（原方案 §11.3）。协议与七面已经在 React 里 |

壳继续是 **React 19 + Tailwind v4 独立 SPA**。原方案写的「按需 `@pier/ui` 子集」仍然成立，但当前 `dependency-cruiser` 还没放行——落地时再开白名单，不要为了换皮去换框架。

发硬的根因是交互层空着：

1. Tailwind 预检通常会把 `-webkit-tap-highlight-color` 清成透明，又没有自绘 `:active`。
2. 多数列表不是整行命中；主机页把「进入 / 移除」做成 28px 级小钮。
3. Hash 切页是整页瞬切：有「返回」却没有反向运动，空间记忆对不上。
4. 工作台把打开中的文档面板和审查面板列成和终端平级；实现里变更还会 `git.openReviewPanel` 同步桌面。
5. 桌面 28px 密度被带进了手机。

要补的是 **触控积木**，不是第三套 UI 框架：按下态、44px 命中、整行进入、层级栈、铃铛收件箱。过渡优先用 View Transitions API，不必上路由库。

## 3 两份真源，不要并成一份

| 真源 | 管什么 | 不管什么 |
|---|---|---|
| 移动端方案 §11 | 页面、区块、字段、动作、事实源 | 色、圆角、底栏造型、按下动画 |
| 本文件 + 画板 | 触控、密度、色、七面外观、页面过渡 | 不改信息架构、不改帧协议 |

曾经用 `.pier/canvases/mobile-companion/` 当线框真源，已删。**新画板只是视觉稿。** 增删页面或改闭环，改 §11，不要改画板当协议。

## 4 触控语言

画板 `K1` / `P0` 是对照。实现时收成公共控件，禁止每页手写一套 `active:bg-neutral-800`。

| 规则 | 要求 |
|---|---|
| 按下 | 主路径自绘 `bg-interactive-active`（或主按钮 `opacity-80`）。禁止把 hover 当唯一反馈 |
| 命中 | 主按钮与列表行 `min-h-11`（44px）。会话底栏键帽同高 |
| 行 | 整行进入。主机「移除」不得和「进入」并排抢主路径；破坏动作后置（溢出或确认） |
| 过渡 | 见 §5。有返回 = 必须有反向滑出。没有底栏 |
| 系统高亮 | 可以继续关掉 UA tap 高亮，但必须有自绘按下态顶上 |

不要上震动反馈当 v1 必达（Web 壳没有稳定触觉）。不要为了「像 iOS」去引入橡皮筋列表库。

## 5 页面过渡（工效）

**整页瞬切不是手机工效的默认。** 人靠空间记忆走路：进去是更深一层，回来是揭开上一层。桌面网站可以整页替换；手机上瞬切会让人失去「我从哪来」。现在的壳用 hash 直接卸掉整棵页面树（顶栏也一起死），所以切面像在换网站，不像在同一台设备里往里走。

三类动作三种运动，禁止混用：

| 动作 | 例子 | 运动 | 时长 |
|---|---|---|---|
| 推入栈 | 主机 → 这台电脑 → 会话 → 变更 / 文件；主机 → 配对；工作台铃铛 → 通知 → 该会话 | 新页从右进，底页左移约 25%。只动 `transform` | 220ms，曲线 `cubic-bezier(0.32, 0.72, 0, 1)` |
| 返回 | 顶栏「返回」、系统后退 | 与推入同曲线反向。有返回控件就必须有这步 | 200–220ms |

**不要底栏。** 主机和工作台不是平级频道：先选电脑，再看这台电脑上的面板。通知也不是第三个根面：它是当前机的收件箱，入口是工作台顶栏铃铛；系统推送点开直接落到该会话。

业界对照（远程监督，不是云执行）：Orca 根面是已配对主机列表，进主机后再看会话；Codex Remote 是 Remote → 选主机 → 任务；Claude Code Remote 是会话列表（已在某台电脑上跑）；Cursor iOS 收件箱按会话，不是「主机 / 工作台 / 通知」三键；Moshi 的 Home 是连接（主机），Inbox 是钩子事件，仍先连上某台机器。iOS 人机界面：底栏只给同级目的地；父子用推入。

其它规则：

- **实现时状态栏 / 安全区不参与横滑**，只滑导航栏 + 正文。画板外框是 Artboard，内页不再画 9:41 / Home 条。
- **配对**：相机即页。玻璃上只留角括号；一只 44×44 实心停止键；底下那一行说明。不要标题「配对」、不要取景框里再写「对准二维码」、不要绿激光、不要相册/粘贴链。
- **工作台**主列表是活着的会话：需要你处理 / 运行中收成当前屏幕切片（等宽、贴左金条），不要筛选芯片、不要分组标题。普通终端和变更收成标题下一条仪器带。行标题跟桌面标签 short 一致（叶子目录 / 用户钉名），不要写产品 id。
- **会话**当前屏幕铺满玻璃，内容顶对齐像真终端视口。顶栏只留返回、会话名、git、文件。点标题下拉切同机其它会话（覆盖层，不推入）。未等待不挂键。智能体需要你处理时，把本屏需要的键（示范：1 / 2 / 3 / Enter / Esc）叠在屏幕下缘；只画按键不画「批准 / 拒绝」。双击读屏切换三档字号。不要再单独做「当前屏幕」工具条。
- **变更**最多按 git 根给一条仪器带入口。点进去是 S2：一层顶栏，代码/diff 即页，不装进圆角井。电脑上不会弹出审查。
- **文件**只从会话头部进 S3，工作台不列打开中的文档面板（不要 README 那种行）。目录是等宽 `ls`（目录名带 `/`），标题是 cwd / 叶子；预览折行、铺满玻璃。不要 Files.app 图标和体积。
- **无会话空态**：说明「这台电脑现在没有可投影的会话，请在电脑上开一个」。不要「新建智能体 / 新建终端 / 新建工作树」。
- **文件页在目录里往下走不是推入新页**，只更新列表；推入发生在「会话 → 文件面」。
- **`prefers-reduced-motion: reduce`**：取消位移，改为 ≤120ms 淡入淡出。
- **不要**为过渡引入路由库或整页共享元素动画。不要把终端滚屏、审批键显隐、会话标题下拉做成页面过渡。
- v1 可以不做从左缘滑回；但一旦做，必须走同一套返回动画，不能只改手势不改运动。

画板 `P0` 可点对照。`K1` / `K2` 是规则卡，不用手机画框，也不和说明卡重叠。

## 6 密度、色、文案

- **密度**：桌面 28px 规范不适用于本壳主路径。不要把 `@pier/ui` 默认 `Button` 直接当手机主按钮。
- **色**：只走产品语义令牌（`background` / `card` / `action-accent` / `status-*` / `interactive-active`）。实现里删除 `bg-neutral-*`、`bg-emerald-*`、`text-red-400` 色阶。
- **等待项**：工作台「需要你处理」用当前屏幕切片置顶（左金条 + 等宽最后几行），不要通知中心式摘要卡，不要筛选芯片。
- **通知**：一场会话一行，复用同一块屏幕切片（比工作台更短）；新事件更新同一行，需要你处理钉顶。不要设置行、「全部已读」主按钮、主机级系统句。推送入口若出现必须是暗行。
- **主机**：设备行整行进入，连接态点画在设备图标右下。离线不降整行透明度，点按给去电脑上开的提示；移除放在该提示里，不要顶栏「编辑」。添加入口只留顶栏扫码。
- **实现词**：界面不展示 snapshot revision、交互 id。等待键上不要再写「按键会发到这台电脑的终端」。

## 7 导航

一条栈，没有底栏：

```text
主机（根面）
  ├─ 添加主机 / 配对
  └─ 这台电脑（工作台，标题=电脑名，返回=主机，右侧=铃铛）
        ├─ 会话 → 变更 / 文件（会话内标题下拉切同机其它会话，不推入）
        ├─ 变更 · git 根（可选快捷入口）
        └─ 通知（铃铛）→ 该会话
```

- 换机：从工作台返回主机列表，再点另一台。不要用底栏切换假装「还在同一层」。
- 系统叫醒点开：直接落到该会话；返回沿栈回去（会话 → 工作台 → 主机）。
- 连接态跟在电脑身份旁，不是正文调试行。

## 8 实现边界

- 不改帧协议、配对、会合、推送。
- 不在本轮做 T2 真终端、不引入路由库、不上 RN。
- 画板用 `pier/canvas` 积木在桌面里预览；量产控件活在 `apps/mobile-web`，不要从画板 import 进 SPA。
- 落地 PR 建议顺序：① 触控积木 + 令牌 + 安全区；② 主机→工作台层级栈 + 铃铛；③ 按画画七面；④ 推入/返回过渡。
