## 0. 一句话

**工作树是单元，tile 是它在某个窗口里的一棵 pane 树，窗口装 1…N 个 tile，恰好一个窗口带侧栏。** 主窗口默认只显示一个 tile（Orca 形态），子窗口默认显示全部 tile（Cursor 3.1 的 tile 墙）；tab 只能落在自己工作树的 tile 里，tile 可以落到任何窗口。工作树的事实（分支、`±N`、`↑↓`、状态）只写在 **tile 底部的一条状态栏**（今天每终端状态栏的位置，只是每 tile 一条）；每终端状态栏与窗口级状态行都不存在。

## 1. 根因：单元选错了

Pier 今天把**面板**当排布单元，任何工作树的任何面板可以摆在任何窗口的任何位置。业界（§2）无一例外把**工作树 / 会话**当完整单元。单元选错，所有事实都没有容器可放：工作树的分支、`±N` 只能贴在每个终端上（状态栏 ×N）；会话状态只能在 tab、状态栏、标题栏各画一遍；「这块属于谁」只能靠标签、颜色、消歧去补。09-03 提案用改名与菜单补，同日两版草稿用侧栏 + 标签补，都是给错误单元打补丁。本文换单元。

## 3. 候选与选择

| | A 一窗一单元（Orca） | B 完整单元平铺（Cursor 3.1） | C 自由面板 + 组标签 | D VS Code 多根混放 |
|---|---|---|---|---|
| 单元 | 工作树 | 工作树 | 面板 | 文件 |
| 监控墙 | 只能多 OS 窗口 | 一窗多 tile | 可以但混乱 | 可以但混乱 |
| 拖拽 | tab 限单元内 | tab 限单元内，单元在 tile 间拖 | 任意 → 需定义混合 | 任意 |
| 每单元布局记忆 | 有 | 有 | 无 | 无 |

**选择：A + B 的统一形态**——「每个窗口装 1…N 个工作树 tile，恰好一个窗口带侧栏」。主窗口默认 1 个 tile（= A），子窗口默认 tile 墙（= B）。C / D 淘汰。

## 4. 对象模型

```text
工作区（本机 + 已连主机）
 └─ 项目（git 仓库 = 主 checkout 代表；非 git 目录是只有一个工作树的退化项目）
     └─ 工作树 = 单元（主 checkout 也是；非 git 目录、~ 是退化单元）
         ├─ 身份：名字（叶子目录 / 用户钉名）、分类色（--identity-1…6，本工作区首个空闲槽位，按 worktreeKey 落盘）
         ├─ 事实：分支、±N、↑↓（git）
         ├─ 会话：终端 / 智能体 / 项目命令（归属 = 创建时 cwd 所属工作树）
         ├─ 文档：文件、diff、预览（归属 = 路径所属工作树）
         └─ 状态 = max(会话状态)（三值聚合，见 §7.1）
窗口 = 取景框：1…N 个 tile；恰好一个窗口带侧栏（主窗口）
tile = 工作树 × 窗口 → 一棵 pane 树（dockview：分组 → tab → 视图）
```

- **视图属于对象所属的工作树**（R1，推导不指派）。从工作树 A 的终端点开工作树 B 的文件 → 在 B 的 tile 里打开并聚焦 B；不在 A 里混放。
- 同一工作树可以在多个窗口各有一个 tile（屏 1 终端、屏 2 diff）；一个**视图**同一时刻只在一个 tile 里（原生 surface 不镜像）。身份 / 事实 / 状态按工作树共享，**布局按 tile 记**。
- 每个窗口都有「可见 tile」与「隐藏 tile 集」（隐藏不卸布局）。主窗口默认只显示一个 tile，其余隐藏；子窗口默认显示全部 tile，只有被弹簧替换的 tile 进入隐藏集。**同一窗口内同一工作树至多一个 tile**（R12）。主窗口恒有至少一个 tile：最后一个 tile 的最后一个视图关闭后回到欢迎态（`~` 退化 tile）。
- 退化单元（`~`、非 git 目录）在侧栏归入「本机目录」分组，只在它有视图时出现。**欢迎态的 `~` 区域不进侧栏**——它就是「还没有项目」本身，侧栏保持空态 + 最近。只含初始空闲终端的 `~` tile 在打开项目后自动关闭，不进隐藏集。用户打开非 git 目录、或在欢迎态之外主动保留了退化单元，才出现「本机目录」。
- 聚合只有一个函数：`max` 按 §7.1 优先级（需要你处理 > 运行中 > 空闲；完成未查看只加粗、不聚合），从会话 → 工作树 → 项目 → 窗口 → 工作区。

## 5. 层级与事实归属

| 层 | 表面 | 拥有的事实 | 不得出现 |
|---|---|---|---|
| L0 工作区 | 侧栏（仅主窗口）；Quick Pick（任何窗口，同源） | **拥有**：上半「项目」树（项目 → 工作树 → 会话）、下半工作区级插件目的地、身份的定义处、会话所在窗口；**引用**：聚合状态、`±N`（索引列，R2） | 分支名（属 tile 状态栏）；插件内部对象（议题卡、看板列）；把插件目的地嵌进某个项目；常驻动画；「最近」（只在空态） |
| L1 窗口 | 标题栏 | 窗口名（[窗口显示名金标准](2026-09-04-window-os-title-gold-standard.md)）；侧栏开关（主窗）/「+ 工作树」（子窗）；工作区聚合计数（为 0 留空）；铃铛 / 更新 | 当前工作树名（那是 tile 状态栏的事） |
| L2 tile | tile 状态栏（tile **底部**一行，28px） | 固定槽位：最左 `■ 名字`（身份，tmux status-left 先例）· 聚合状态点 · 分支 · `±N`（可点 = 查看更改）· `↑↓`（可点 = 同步）· 最右 `⋯`（工作树动词表）。槽位恒定，值空则留空 | 会话状态文字（tab 的事）；评论数（审查工具栏的事）；第二个 `+`（分组 tab 条已有） |
| L3 pane 树 | 分组 tab 条 | 视图列表、活动视图、每视图一个状态指示（顶缘线 / 滑块 + 需要处理图标） | 分支、`±N`、身份 |
| L4 视图 | 正文 + 内容工具栏 | 内容与内容动作（审查：范围 / 拆分 / 发送给智能体 / 提交） | 每视图状态栏、身份、全局状态 |

每层用「色块 + 名字」说明自己在讲哪个工作树（侧栏行、tile 状态栏）；这是宾语绑定，不算重复。

### 5.1 窗口身份路径（与窗口显示名金标准的接口）

[窗口显示名金标准](2026-09-04-window-os-title-gold-standard.md) 规定对外窗口名 = 工作区叶子名 + 撞名限定。本文补它的输入：**窗口记录持有一个锚 tile**（该窗口第一个 tile 的 `worktreeKey`；关闭时按 tile 创建序顺延；`⋯`「设为窗口名称」可重钉）；`menuLabel` 只从锚 tile 的工作树叶子名派生，主窗口切换可见 tile **不改**锚。格式固定 `锚叶子 · +N · 限定`：N = **可见** tile 数 − 1（隐藏 tile 不计，主窗默认 N = 0 不显示）；撞名限定只比锚叶子，`+N` 段不参与消歧。退化单元 `~` 的叶子名就是 `~`（首启窗口名 `~`，不显示应用名）。这样标题栏永远是窗口身份，tile 状态栏永远是当前工作树，两者不再互斥。**没有窗口级状态行，没有每终端状态栏，tab 上不重复工作树标识**（tab 永远在自己工作树的 tile 里，tile 状态栏就是它的归属）。

### 5.2 侧栏：项目树 + 插件目的地（不多做一层）

侧栏是索引，不是第二套工作台。结构只有两块，上下平级，中间发丝线切开：

1. **项目。** 页头「项目」。树 = 项目 → 工作树 → 该工作树的会话。项目行 `+` = 新建工作树。会话行前置图标必须是对应智能体的品牌图标（产品 `AgentIcon` / `panel-tab-leading-icon` 同一套）；普通终端用终端图标。禁止用提供方首字母方块冒充品牌。
2. **插件目的地。** 工作区级一行一个（贡献点 `sidebarEntries`，纪律链与 `panels` 同款：未声明不出现）。任务跟踪的「任务」是第一个例子：点它，在**当前可见区域**打开已有的 `pier.tasks.board`（项目上下文 = 当前工作树，R8 同类可重定向）。命令面板与新建菜单仍作发现入口（侧栏折叠、子窗口没有侧栏时）。

硬边界：

- 「任务」在左侧只有**一条**，和「项目」树平级，不挂在某个仓库下面，也不按项目复制。
- 不列出插件内部对象（议题、看板列、连接）。议题语义仍归 `plugin-tasks`。
- 不为同一入口再画标题栏按钮、空 tile 大按钮、侧栏内嵌看板。
- 不进工作树聚合状态，不占用身份色块。
- **任务在项目树之下。** 发丝线只切开这两块；禁止把「任务」画在页头「项目」之上。

### 5.3 侧栏视觉词汇（L0 行形）

本节补 §5.2 的行形与几何。产品组件是视觉真源。`.pier/canvases/workbench-shell` 是整窗 IA（主窗口 / 子窗口 tile 墙 / 拖拽 / 解剖 / 首启），不能 import 产品原语，不得当治理对照物。

**已决（对照评审时不再当未决）：**

| 事实 | 归属 | 侧栏 |
| --- | --- | --- |
| 分支名、`↑↓` | tile 状态栏（R2） | **不得出现**（画在区域底栏） |
| `±N`、聚合状态 | tile 状态栏拥有；侧栏只引用 | 工作树行右侧 `±N` + **一个**聚合状态点 |
| 本机目录 | §4 退化单元分组 | 有视图才出现；欢迎态 `~` 不进侧栏 |
| 普通终端会话 | §5.2 | 列入，终端图标 |
| 跨窗会话 | §11 / §12 | 标窗口名 |
| SSH | §11 | `主机 → 项目 → 工作树` |
| 红绿灯 / 折叠 / 铃铛 / 更新 | L1 标题栏 | 不进侧栏本体 |

**行形（新决）：**

- 所有可点单行 **28px**（与交互密度规范同一高度）。
- **页头「项目」：** 无图标、无色块。
- **项目行：** 折叠箭头 + 名字；**无身份色块、无仓库/文件夹图标**。项目行 `+` 仅 hover / focus-within 显现。
- **工作树行：** 色块 + 叶子名 + 可选「主目录」+ 右侧 `±N` + 一个聚合状态点（引用）。无分支、无 `↑↓`。选中 = 侧栏强调底。
- **会话行：** 需要你处理 / 运行中才画状态点；智能体用产品品牌图标（画布占位对齐 `AgentIcon`）；普通终端用终端图标。跨窗：窗口 `menuLabel` 文本；本窗不标。
- **本机目录：** **分组标题**（不是项目行）；无色块、无仓库图标。子行才是退化工作树（有色块）。
- **SSH 主机行：** 分组标题，无身份色。其下才是项目 → 工作树。
- **插件目的地：** 发丝线下方；一行；无身份色块。
- **打开项目…：** 侧栏底与区域状态栏同高同线（28px）；空态与非空态都在。

**缩进：** 单一来源数字，**项目 < 工作树 < 会话**，单调递增。画布常量 `INDENT_PROJECT_PX` / `INDENT_WORKTREE_PX` / `INDENT_SESSION_PX`。

**加载：** 滑块贴在该对象自己的边（R6）。禁止 Spinner。

**IA 画布（`workbench-shell`）必须覆盖：** B1 主窗口（侧栏 + 一个 tile + 底栏分支）；B2 子窗口 tile 墙（无侧栏）；B3 拖拽落点；B4 解剖；B5 首启与加载。红绿灯只出现在标题栏。

## 6. 规则

- **R1 推导优先。** 归属由 cwd / 路径 / gitRoot 推导；用户不指派；上下文未解析是有定义的瞬态（§7.3）。
- **R2 一事实一层。** 每类事实只有一个**所有者层**（§5）。L0 侧栏是索引：它**引用** `±N` 与聚合状态（读同一数据源、不另算、不另存），不拥有它们；tile 状态栏拥有工作树事实，tab 拥有视图状态。治理测试据此写：事实的写入 / 计算只在所有者层。
- **R3 结构恒定，内容随值。** 每层的槽位永远存在，不因窗口里有几个 tile、侧栏是否折叠而出现或消失；值为空则留空。主窗口 1 个 tile 与子窗口 4 个 tile 长得一样，只是数量不同。
- **R4 状态一套词汇。** 四值、一套颜色、一种运动（不定长滑块）；同一对象的状态在一个表面上只画一次。
- **R5 身份一套词汇。** 色块 + 名字；分类色与状态色相斥；从不占用表示状态的边。
- **R6 加载是对象状态。** 滑块贴在加载对象自己的边上（tile 状态栏顶缘 / tab 顶缘 / 侧栏头部）；大块内容用骨架；tile 状态栏与 tab 条同帧切换、正文可晚到但不能显示别的工作树的内容；后台失败原位静音 + 重试；没有 Spinner、虚线槽位、逐行骨架。
- **R7 窗口是取景框。** 任何窗口装 1…N 个 tile；主 / 子窗口除侧栏外规则相同。
- **R8 导航到对象。** 侧栏 / 通知 / 深链导航到工作树、会话或插件入口，由系统选 tile 与视图（§9.4）；同类可重定向视图（审查、目录树、任务跟踪）按目标原地切换，不叠 tab；会话视图永不重定向。
- **R9 动作附着对象。** 每个对象一张动词表（§10），右键 / `+` / 命令面板 / 快捷键是同一张表的不同入口；没有无宾语的全局菜单。
- **R10 持久化跟对象。** tile 布局 → 窗口记录（按工作树键控）；身份偏好（颜色、置顶、钉名）→ 按 `worktreeKey`；视图偏好 → 按视图种类；不新增台账。
- **R11 可预测、可见、可确认——对不知道规则的人。** 每条改变预期的规则配预告 / 一次性反馈 / 回退（§12）；验收对象是第一次用的人，不是作者。
- **R12 tile 键唯一。** tile 键 = （窗口，`worktreeKey`）；同一窗口内同一工作树至多一个 tile；边缘分屏不能复制同工作树 tile，落到已有 tile 即合并。

## 7. 统一词汇

### 7.1 状态（四值）

| 状态 | 来源 | 颜色 | 运动 |
|---|---|---|---|
| 需要你处理 | Index `waiting` / `error`；命令 `blocked` / `failed` | `warning` | 无（出现时一次 300ms 淡入） |
| 运行中 | `processing` / `tool` / `launch`；命令 `running` | `info`（tab 顶缘按现有 S1 / S2 / S3 档） | 不定长滑块 |
| 完成未查看 | 回合结束 + 该视图有未读 `agent.turn-finished` / `agent.attention` | 无颜色：只加粗名字（tab、侧栏会话行、侧栏工作树行） | 无 |
| 空闲 | 其余 | `neutral` | 无 |

优先级即表序。`max` 聚合到工作树 / 项目 / 窗口 / 工作区时只取「需要你处理 > 运行中 > 空闲」三值；「完成未查看」不进聚合点，只让名字加粗（它是「你还没看」的标记，不是对象的运行状态）。加载（R6）是「运行中」在非会话对象上的同一运动，不另设状态值。

### 7.2 身份

名字 = 叶子目录名，用户可钉名（现有 `user` 标题域）；主 checkout 的名字 = 项目名，侧栏加「主目录」标记；跨项目同名 → `项目/工作树`，跨主机同名 → `主机/项目/工作树`（沿用窗口显示名消歧链）。颜色 = `--identity-1…6` 分类色板：新工作树取本工作区**首个空闲槽位**（不是哈希，避免 6 色必撞），按 `worktreeKey` 落盘（R10），可右键改；出现形式永远是色块 + 名字。色板由 `globals.css` 持有（颜色规范的所有者），约束：oklch 色度 ≤ 0.10；色相两两间隔 ≥ 25°，且避开状态色相带（danger 0–50°、warning 40–90°、success 120–170°、info 215–265°）；色块对 `--sidebar` 与 `--background` 的对比 ≥ 3:1；亮暗主题各一套亮度。初始值：

### 7.3 上下文未解析

新终端 cwd 未到、gitRoot 未解析：暂归「待定」，tile 状态栏显示 cwd 叶子、无色块、无分支；解析成功走下面的重绑规则（无颜色过渡）。从侧栏行 `+` / 分组 tab 条 `+` 创建的终端 cwd 已知，不经过此态。终端 `cd` 到另一工作树**不迁移**视图（Orca）；终端自己的 live cwd 只表现在 tab（OSC 7 叶子名）与 tooltip 全路径，tile 状态栏始终是 tile 的工作树。例外：在 `~` / 非 git 退化单元里的终端 `cd` 进**工作区里已有的项目 / 工作树**时——不是把视图搬走（主窗只显示一个 tile，搬走就消失），而是 **tile 重绑**：该退化 tile 只有这个终端时，tile 本体变成目标工作树的 tile（状态栏原地换、恢复目标工作树的记忆布局并合并）；若目标工作树在本窗已有 tile，则本窗切换显示到它并给一次 300ms 高亮（§12）。上下文未解析 → 解析成功走同一条重绑规则。`cd` 进不在工作区里的其他仓库：保持退化 tile，tab 显示 cwd 叶子，状态栏 `⋯` 提供「作为项目打开」，不隐式加项目。

## 8. 主窗口与子窗口

| | 主窗口（恰好一个） | 子窗口（0…N） |
|---|---|---|
| 侧栏 | 有（L0），`⌘B` 折叠 | 无；标题栏「+ 工作树」打开同源 Quick Pick |
| 默认显示 | 1 个 tile；其余进隐藏集，切换即恢复各自布局 | 全部 tile（tile 墙）；「+ 工作树」/ 拖到 tile 边缘 / `⋯`「在旁边打开工作树…」分出新 tile（`⌘D` 保持今天的分组分屏，不复用）；被弹簧替换的 tile 进隐藏集，「+ 工作树」里可恢复 |
| tile 数量 | 1…N（允许分屏成多个，但默认 1） | 1…N |
| 空态 | 欢迎态：一个普通终端 tile（退化单元 `~`），侧栏空态 + 最近 + 打开项目 | 没有 tile 即关窗 |
| 关闭 | 关主窗 = 关全部子窗（VS Code 浮动窗语义），走现有关窗保护 | 走现有关窗保护；可见与隐藏 tile 的全部视图都计入（§9.3） |
| 铃铛 / 更新 | 有 | 铃铛有（NCS 投递到 key-window 的既有规则不变），更新无 |
| 创建入口 | 侧栏行 `+`、分组 tab 条 `+`、`⌘N`、命令面板 | 分组 tab 条 `+`、`⌘N`、命令面板、「+ 工作树」 |

tile 的结构自上而下：该工作树的 dockview（分组 tab 条照旧；tab 只表示视图状态，不带工作树标识）→ **tile 状态栏**（底部一行 28px，槽位恒定：`■ 名字 · ● · 分支 · ±N · ↑↓ ……… ⋯`；`±N` 即「查看更改」的触发器，沿用今天 `GitChangesStatusItem`；`⋯` 打开工作树动词表；新建走分组 tab 条的 `+`，状态栏不再放第二个 `+`）。窄 tile 溢出顺序：`■ 名字`、聚合点与 `⋯` 固定；`↑↓` 最先隐藏，分支名先截断后隐藏，`±N` 最后。「主目录」标记只在侧栏，不进状态栏。混合态不存在（tile 只属一个工作树）。位置沿用今天状态栏在底部的习惯（VS Code / iTerm2 / tmux status line），只是从「每终端一条」变成「每 tile 一条」。

## 9. 创建 · 拖拽 · 关闭 · 定位（对所有窗口对称）

### 9.1 创建

| 入口 | 宾语 | 落点 |
|---|---|---|
| 分组 tab 条 `+` | 该 tile 的工作树 | 该分组 |
| `⌘N` / 命令面板「新建终端 / 启动智能体」 | 聚焦 tile 的工作树（窗口恒有 tile：子窗无 tile 即关窗，主窗回欢迎态） | 聚焦 tile 的活动分组 |
| 「新建工作树…」「打开项目…」 | 新单元 | **在发起的窗口**新建 tile（主窗切换显示到它；子窗追加） |
| 子窗口「+ 工作树」 | Quick Pick 选一个 | 追加 tile |
| 侧栏**工作树**行点击 | 该工作树 | 主窗切换到它的区域（可空：本窗没有视图也不跳到别的窗口；有隐藏 tile 则恢复其布局） |
| 侧栏**会话**行点击 | 该会话 | §9.4 定位（可以跳到别的窗口） |
| 侧栏**插件目的地**点击（例：任务） | 该插件已声明的面板 | 在当前可见区域打开或重定向；项目上下文 = 当前工作树；不跳窗、不新建工作树 |
| 侧栏行 `⌘`+点 / 右键「在新窗口打开」/ 拖到桌面 | 该工作树 | 新子窗口，含它的一个 tile。用户文案里 tile 叫「区域」（如「只能放进 pier-login 的区域」），`tile` 只是本文的实现词 |
| 通知「查看更改」 | 该工作树 | §9.4 |

依据：VS Code 多根下新终端必须选文件夹或跟活动编辑器（`newInActiveWorkspace`）；Zed `terminal.working_directory` 默认 `current_project_directory`——「新建」不能没有宾语。

### 9.2 拖拽

| 拖的是 | 落点 | 结果 |
|---|---|---|
| tab | 同 tile 内 | dockview 现有语义 |
| tab | 同窗口的其他 tile（正文 / 状态栏 / 边缘） | **一律拒绝**：R12 下本窗已有它的 tile（**含隐藏集**），落别处会产生第二个；提示「pier-login 在本窗口已有区域」并高亮 / 恢复已有 tile |
| tab | 另一窗口，那里有同工作树的 tile（**含隐藏集**） | 若该 tile 隐藏则先恢复为可见（主窗 = 切换显示；子窗 = 从隐藏集拿出），然后它是唯一落点；其他 tile 全部拒绝 |
| tab | 另一窗口，那里没有同工作树的 tile（可见与隐藏都不算）：落任一 tile **正文 / 状态栏** | **弹簧替换**（与 tile 数量无关）：悬停 ~0.5s 后该 tile 切换为 tab 的工作树，被替换的 tile 进隐藏集；松开即落入；拖出未落则换回 |
| tab | 另一窗口，那里没有同工作树的 tile：落 tile **边缘** | 为该工作树新建 tile（与 tile 数量无关；单 tile 窗口由此变成两个 tile） |
| tab | 桌面 | 移到新窗口：成为新子窗口（现有 tear-off） |
| tab | 侧栏行 | 拒绝：侧栏是索引不是容器；归属由 cwd / 路径决定 |
| tile（拖状态栏） | 同窗口 | 换位 / 分屏 |
| tile | 另一窗口 | 整个 tile 移过去；那边已有同工作树 tile → 两棵 pane 树按落点合并 |
| tile | 桌面 | 移到新窗口：成为新子窗口 |
| 侧栏行 | 任意窗口内容区 | 在落点为该工作树新建 tile（已有 → 高亮已有 tile） |
| 分组（dockview group）拖动 | 任意 | 分组 = 同工作树的 tab 集合，整体按 tab 规则 |
| 拖拽 ghost | — | 允许带该工作树色块（瞬态，是 §12「拖 tab 会落到哪」的预告）；落定后 tab 本体不带标识 |
| 落点预览 | 沿用 dockview 落点浮层金标准 | 不预告状态栏变化；落下后一次重算 |

一句话：**tab 只能落在自己工作树的 tile 里；落不到就让那个位置变成自己工作树的 tile——已有（含隐藏）则恢复，停在没有的 tile 上是弹簧替换，落在边缘是新建；tile 和侧栏行可以落到任何窗口。** 规则与 tile 数量无关（R3 / R7）。 依据：Orca（tab 限工作树内）、Cursor 3.1（拖的是会话）、Vivaldi「Drop to tile」、macOS 弹簧式文件夹、VS Code 浮动窗互拖。

### 9.3 关闭

| 动作 | 语义 |
|---|---|
| tile「隐藏」 | 进隐藏集，视图与进程不动；子窗口「+ 工作树」按钮显示隐藏数（`+ 工作树 · 2 已隐藏`），Quick Pick 里可恢复。主窗隐藏当前可见区域后，显示隐藏集里最近一次可见的那个；隐藏集空则回欢迎态 `~` |
| tile「关闭全部视图」 | 破坏性：走现有关窗保护逐视图确认；tile 消失（主窗：切回创建序上一个 tile；子窗：没有 tile 时关窗）；工作树仍在索引，布局记忆保留 |
| 关 tile 里最后一个视图（逐个关 tab） | 同上一行的结果，无额外确认 |
| 关子窗口 | 现有关窗保护，**可见与隐藏 tile 的全部视图都计入**（确认文案写明「含 N 个已隐藏区域」）；视图随窗关闭 |
| 关主窗口 | 关全部子窗口，同一保护 |
| 删除工作树 | 破坏性确认；关它在所有窗口的 tile；`worktree.list` 行消失 |

### 9.4 定位（侧栏 / 通知 / 深链 / `⌘⇧Y`）

目标工作树有活体 tile → 激活那一窗并聚焦该 tile → 视图；多处都有 → 优先含目标视图处；哪儿都没有 → 主窗口切换到该工作树的 tile 并显示**空 tile 态**（状态栏 + 「新建终端」「启动智能体…」两个动作），**不**自动创建进程。到达即标记「完成未查看」为已读。同类视图重定向：查看更改 → 该工作树 tile 里已有审查视图则原地切范围，否则在其活动分组新开。

侧栏两条路径不要混：**工作树行**只切换主窗（§9.1），即使该工作树的会话在别的窗口；**会话行 / 通知 / 深链 / `⌘⇧Y`** 才走本节跳窗。

| 颜色是不是出错 | 身份色永远与名字并置；身份 = 实心方块，状态 = 圆点 / 顶缘线；饱和度分带 | tooltip「pier-login 的标记色 · 右键可改」 | 右键改色 | 指着色块问含义 |

| 为什么加粗 | tooltip「已完成，你还没有查看」 | 定位后恢复 | — | 问含义 |
| 加载还是坏了 | 滑块只在对象自己的边；>10s 原位「仍在读取…」 | 完成滑块消失内容淡入；失败原位重试 | 重试 | 大仓 / 断网观察 |
| 子窗口怎么加东西 | 标题栏「+ 工作树」常驻（有隐藏 tile 时带「N 已隐藏」）；`⌘N` 宾语永远是聚焦区域 | 新区域出现在发起处 | 关区域 / 隐藏 | 让用户在子窗新开一个工作树的终端 |
| 主窗与子窗什么关系 | 侧栏会话行标窗口名；关主窗前确认「将关闭 N 个子窗口」 | — | 取消 | 让用户解释关系 |

机制只允许预告 / 一次性反馈 / 回退，不得变成常驻动画或引导浮层；`prefers-reduced-motion` 下闪烁与淡变立即到位。

## 13. 与今天实现的映射与迁移

| 现有 | 目标 |
|---|---|
| `WorkspaceHost`：一窗一棵 dockview | 每个 tile 一棵 dockview（`WorkspaceHost` 参数化为 tile）；窗口内 tile 排布用外层 split（首版可用简单 grid / 单 tile）。Ghostty 原生 surface 随隐藏 tile 的既有可见性机制处理 |
| `PanelContext`（cwd / gitRoot / worktreeRoot） | tile 归属：创建时 `worktreeKey`；live cwd 变化按 §7.3 处理 |
| 窗口记录 `layout` | 窗口记录：`tiles[]`（工作树键 + 该 tile 的 dockview 布局）+ 主窗 `visibleTile` + 侧栏折叠 / 宽度。老布局迁移：按面板 `worktreeKey` 分入 tile，各得一棵 pane 树；主窗只显示当时活动面板所属的 tile |
| panel-transfer / tear-off | 保留 tab 级；新增 tile 级 transfer；跨窗 tab 落点校验 + 弹簧切换 |
| 终端状态栏 `terminalStatusItems`（智能体 / 评论 / 分支 / ± / 同步 / 项目） | 贡献点迁为 `tileStatusItems`（输入 = tile 的 `PanelContext`），位置不变（底部），粒度从每终端变为每 tile：分支 / ±（即查看更改）/ 同步保留；「项目」变为最左的 `■ 名字`；智能体状态只在 tab；评论进审查工具栏与终端增强输入芯片；溢出策略沿用现有 pinned 机制（§8 顺序） |
| `AgentIndexCountsControl` / Quick Pick / Index `focus` | 侧栏数据源；`focus` 目标改为「工作树 → tile → 视图」；Quick Pick 保留为子窗与折叠态入口 |
| GIT 审查、Files 面板 | 都是 tile 内的视图；跨工作树打开 → 去该工作树的 tile |
| 铃铛 / 通知 / NCS | 不变；深链走 §9.4 |
| `⌘B` `pier.view.toggleSideTree` | 改为侧栏折叠；面板内树切换改 `⌘⇧B` |
| `⌘[` / `⌘]` | 主窗：侧栏序上一个 / 下一个工作树；子窗：上一个 / 下一个可见区域。不注册为宿主全局滚动键，也不改 Ghostty `goto_split`：终端聚焦时 `[` / `]` 组合仍归 PTY / Ghostty；区域切换只在非终端焦点（或显式「工作树」命令）时触发 |

第一阶段允许子窗口保留今天的自由 dockview（含每终端状态栏，它在混放环境里就是每个终端的归属标识）作为过渡；主窗口从第一阶段起就是侧栏 + tile 状态栏。终态子窗口也是 tile。
