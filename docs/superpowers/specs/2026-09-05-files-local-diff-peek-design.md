# Files 源码与 Markdown 局部修改预览

实施计划：[2026-09-05-files-local-diff-peek.md](../plans/2026-09-05-files-local-diff-peek.md)。本规格替代 2026-08-08 的 gutter 点击直达完整审查方案。

## 用户行为

文件左侧色条回答“这里改了什么”。单击打开只读差异，同一处再点关闭，另一处替换；每个面板至多一个。hover 只加粗色条并在 400ms 后显示提示。源码与 Markdown 都比较 HEAD 和当前文档，包含未保存编辑；保存和暂存不会切换比较基线。

- 源码：在点击行下方插入 CodeMirror block widget，不改变光标和文字选择；只做必要的滚动。色条占独立 16px 槽位，默认 3px、hover 5px；删除用短横线。
- Markdown：按块旁色条的 range ID 打开非模态 Popover，默认显示渲染后的文档差异，并提供“预览 / 源码”切换。宽度不超过 640px / 面板减 24px，碰撞边界为当前预览；随锚点移动，锚点完全离开可视区时关闭。无可见块的修改仍能从顶部“查看修改”访问。正文、大纲和评论只消费既有布局常量。
- 源码差异展示完整连续修改、前后最多三行未修改内容、真实两侧行号、加减号和行内高亮；长修改由 Pierre 虚拟化滚动。渲染差异展示完整相关 Markdown 块，保留删除内容。两种视图的正文高度均不超过 min(320px, 视口高度的 45%)。
- 工具栏显示比较基线、完整审查、关闭；Markdown 使用共享 `TabsList variant="line"` 的下划线标签切换预览 / 源码，内容与选中标签具有对应的 tabpanel 语义，支持左右方向键。窄面板允许按控件组换行。多处修改时才显示当前位置 / 总数与上一处、下一处。首尾不循环。命令面板提供同一入口；Alt+F5 / Alt+Shift+F5 仅在 Files 面板生效。色条不逐行进入 Tab 序。
- 键盘打开聚焦预览操作；Escape 返回编辑器或调用控件。正文点击、文件/模式/面板切换、宿主 Dialog、内容或 HEAD 版本变化关闭旧预览，关闭不抢其他控件焦点。

## Markdown 差异内容

2026-09-05 行业调研后的实施计划见 [Markdown rendered diff](../plans/2026-09-05-markdown-rendered-diff.md)。参考 [VS Code 的 Markdown diff 预览](https://code.visualstudio.com/docs/languages/markdown#markdown-preview-in-diff-view)、[GitHub prose diff](https://docs.github.com/en/repositories/working-with-files/using-files/working-with-non-code-files#rendering-differences-in-prose-documents) 与 [GitBook diff mode](https://www.gitbook.com/blog/what-is-diff-mode)，采用文档呈现与源码核对并存的方式。

- 通过既有 Markdown Worker 解析两侧完整文档，复用 IR 和渲染器，保证引用链接、列表、表格、代码围栏具有完整语法上下文。每个比较资源只缓存最近一对解析结果；过期异步结果不写入已切换的视图。
- 使用原生 jsdiff 有界对齐完整块及短段落词句。兼容的段落、标题保留格式并显示删除线和插入标记；结构变化的列表、表格、标题层级、代码块显示完整旧、新块。全文新增、删除也保留内容。
- 新增、删除链接随正文显示增删标记，不另列地址。已有链接的地址或标题变化在对应链接处用虚线下划线提示；共享 Tooltip 在悬停或键盘聚焦时展示修改前、后的值，点击仍打开当前目标。先以未变化的链接为锚点，再在修改段内按标签或目标对齐，避免按全局序号误配。仅新增、删除引用定义时，也保留相关正文的预览。
- 图片地址及描述变化保留旧值、新值明细。HTML 的不可见属性提示核对源码；纯空白和不可见格式修改直接显示源码，不提供无效的重试操作。
- 历史图片不读取当前磁盘资源：文本基线不包含旧图片字节，显示占位与说明。历史相对链接不跳到可能已重命名的当前路径。
- 比较内容只读，不改任务框、表格列宽偏好或执行 applet。复用文档字体、字号、舒适/宽屏版心与纸面明暗偏好，不重复挂大纲或评论。
- 详细词句对齐最多 16,000 个序列化字符；选中内容最多 200 个块、512,000 个序列化字符。超过预算或无法可靠显示时保留完整源码比较；解析失败才提供重试。渲染模式的性能尚未与下文源码路径的实测混用。

## 完整审查

预览不提供暂存、撤销或回退。完整审查走现有 `openUncommittedChanges`。打开前读取实际审查文件与分组：只有未修改的当前文档和审查两侧全文均相同，才传递精确行号；否则进入已保存文件的首处修改。删除使用旧侧行号。

未保存文档显示“未保存”短标签，基线说明与无障碍描述明确“包含未保存修改”和“完整审查仅包含已保存的修改”，完整审查按钮使用“查看已保存的修改”。没有可审查的磁盘变更时提示先保存，不自动保存。失败保持可理解的错误/重试入口；自然展开/关闭不叠加成功 toast。

## 界面与几何

2026-09-05 用户确认的整体优化保持点击行为与完整差异内容，包括纯新增段落；不改成只有工具栏的预览。

- 源码正文与预览共用右侧留白：正常面板 16px，宽度小于 520px 时 12px。预览右缘位于 minimap 左侧；关闭 minimap 后使用滚动视口右缘（扣除滚动条）。计算包含正文左 padding、左侧 gutter 与 CodeMirror 缩放，不使用额外最小宽度挤占 minimap。
- 预览随正文纵向滚动，横向滚动时保留在可见代码栏内。面板缩放、minimap 开关与字体变化触发布局测量，宽度变化不重建 portal 或夺走键盘焦点。
- 共用一层视觉边界、小圆角、弱分隔线和低对比工具栏。源码由内联预览持有边框；Markdown 由 Popover 持有外框，不再叠加内框。工具栏控件沿用产品 28px 密度、共享图标规格与 focus-visible 样式。
- 差异代码与源码使用相同代码字体、字号及 1.75 倍行高。高度以 Pierre 原生虚拟内容高度加同源上下留白为准，短段落自然收紧，达到既定上限才内部滚动，不使用行数乘固定行高估算。
- 动态高度作为 CodeMirror widget 的几何属性更新。`updateDOM` 保留同一 portal DOM 与光标，刷新 heightmap，避免正文最小高度不变时行号仍沿用旧高度。
- Markdown 保持既有正文、大纲细轨、评论槽位与碰撞边界；浮层内滚动只由差异渲染器持有。预览滚动到边界时不继续滚动外层正文。

## 唯一数据路径

`git.getFileBaseline({root,path})` 是 `git:read` 下的窄只读契约：固定 HEAD OID，按 Git 提供的 rename 旧路径读取有大小限制的 blob，校验读取前后身份并至多重试一次。明确无 HEAD 或文件缺失才返回空基线；非仓库、二进制、超限、编码等不可用与实际读取错误分开。文本使用 Files 相同的解码与换行表示。缓存按工作树 / HEAD / 基线路径，并限制总占用。

`FilesDocument.currentContents` 是当前侧唯一真源。`git-changes/resource.ts` 按文档共享订阅与差异快照，root watch 引用计数；源码 gutter/minimap、Markdown、计数和预览均消费该资源。最后消费者离开后取消计算并释放资源。比较使用现有 `@pierre/diffs` 独立 Worker，150ms 防抖；每个编辑会话分别持有 IME 状态。过期结果不得覆盖新版本。

编辑期间，未触及的源码装饰映射到新位置，旧命中区间失效。HEAD 或路径改变时直接清空旧装饰。Markdown 仅为渲染文本与差异快照匹配的正文画色条，不给懒分页的估计高度制造精确行号。

## 限制与验证

自动比较：双方各不超过 2MiB、50k 行，Worker 预算 2 秒。10MiB 文本上限以内的大文件按需比较，预算 5 秒；超时终止 Worker，无主线程昂贵退路。失败与按需状态保留顶部入口。

测试覆盖真实 Git 仓库的 HEAD/index/工作文件分离、rename、空仓库、新文件、删除、编码和大小限制；覆盖当前文档变化、IME、多实例共享、过期结果、错误恢复、装饰映射、源码 widget、Markdown range 点击和内容一致性、浮层关闭与键盘焦点。真实 Electron E2E 使用仓库远端 runner，验证明暗主题与窄视口并保存截图。性能预算需以实测记录判断，不以单元测试通过代替性能结论。

### 2026-09-05 性能实测

在远端 MacBook Pro（六核 Intel Core i7 2.6GHz、macOS 15.7.7）运行实际 Electron 43 应用，窗口 1100×760。数据为 10,000 行、510,000 字节（约 498KiB）的文本，30 处独立修改。先打开预览预热五次，再测量 30 次打开与 20 次输入更新；P95 取排序后第 `ceil(n × 0.95)` 个值。

| 指标 | 测量范围 | P95 | 预算 |
| --- | --- | --- | --- |
| 缓存打开 | 色条 mousedown 至包含真实差异行的下一动画帧 | 20.1ms | ≤100ms |
| 编辑更新 | input 至修改数恢复 ready 的下一动画帧，包含 150ms 防抖 | 250.4ms | ≤500ms |

测量阶段 Chromium `PerformanceObserver` 没有记录到 `longtask` 条目。以上覆盖已加载文本的源码路径；冷启动、超限文件的按需计算与其他操作系统不在本轮性能样本内。
