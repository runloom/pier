## 架构冻结（本收尾不得推翻）

Web 壳走 Happy / VS Code Tunnels / Nabu Casa 这一家：两端出站，会合云盲转发密文字节。不走 RustDesk / Tailscale 的打洞优先。

| 冻结项 | 内容 |
|---|---|
| 会合云搬字节 | `apps/relay/src/forward.ts` 对 `envelope` 原样搬运；不解封、不存帧、不当事实源 |
| Web 壳一律经会合 | 生产 origin `https://m.pier.codes` 禁止 `ws://` 直连家里 IP（混合内容，无 workaround） |
| 中继不是地址簿 | 「只存 IP 再直连」不是任何一家的唯一通路 |
| 无账号 | 宿主 Ed25519 自证明 + 设备通行证 |
| 推送不经会合云 | 宿主 VAPID 直发浏览器推送服务 |
| LAN 监听保留 | 本网接口给 dev 与未来原生壳；生产 QR 指向官方 origin |

**明确不做：** WebRTC / ICE / TURN、把会合云改成地址簿、用户账号、T2 真终端、App / 小程序壳、给整个 Web 壳新建四语言体系。

## 工作包

### WP0 规格与计划对齐

- 规格仍指导实现的段落改为「官方会合（无账号）」：G5、架构图、§9.2 职责表、§14 对照表、§17.5。
- 四家对照里的「要账号」保留为业界事实；Pier 行写「无账号，身份在配对令牌」。
- 原 M2 计划头部加交付注记，不回头勾 48 个旧复选框。

### WP1 传输诚实性

- 投影页连接横幅：`connecting` / `reconnecting` / `closed`；H0/H1 不显示；吊销不自动复活。
- 主机列表 `/hosts/status` 轮询只在页面可见时跑；隐藏停定时器，回前台立刻刷。
- 会合明确离线 → 列表显示「离线」，禁止「连接中」空转。
- 回前台：已连接拉快照；断线立即重拨；`closed` 不复活。
- 不为在线态再开第二条长连接；不在 HTTPS PWA 上尝试 LAN `ws://`。

### WP2 叫醒闭环

- 非 standalone 只给「加到主屏幕」引导，不出现会失败的订阅按钮。
- 深链只带 `panelId`（`/session?panel=`），不用 `?agent=`。
- 410/404 删句柄；有 key-window 仍 `remotePush`。
- 真机记录阻塞规格 §14 M2 勾选：iPhone 加主屏 → 授权 → 「需要你处理」横幅 → 点开该会话。

### WP3 投影纪律回归

- 无窗口、按 `panelId` 寻址、无 git 不列变更。已有治理测试红了只修投影层。

### WP4 治理 + 会合冒烟

- QR：未配置 `relayHint === null`；配置后为 `wss://` 且带 `hostId` / `pairSecret`。
- in-process 会合冒烟（不跑会打扰主力机的全量 e2e）：uplink → downlink → 密封往返 → 名册删除 → 宿主离线 `host_offline`。
- `pnpm preflight:push` 全绿后才允许勾 §14 M2。

### WP5 落地

- 按主题提交；不把宿主 `v*` 和 `relay-v*` / `mobile-web-v*` 绑死。
- 规格 §14 M2 在六条验收（含叫醒真机）过完再勾。

## 真机叫醒记录（阻塞 §14 M2 勾选）

在 iPhone Safari 上走一遍，把日期与结果记在 PR 描述：

1. 把 `https://m.pier.codes` 添加到主屏幕，从图标打开（standalone）。
2. 扫码配对（sweep 后须是新配对）。
3. 通知页点「开启提醒」并允许通知。
4. 把 PWA 切到后台或锁屏。
5. 电脑上让智能体进入「需要你处理」。
6. 锁屏出现横幅；点开落到该会话（hash 含 `panel=`，不是 `agent=`）。

未完成此记录不得勾规格 §14 M2。

## 验收

- 生产 PWA 扫码一次后跨网打开不填地址、不登录（sweep 后的新配对）。
- 电脑未开：列表「离线」，无连接中空转。
- 电脑开启远程访问并唤醒：点入工作台能看终端 / 变更 / 文件投影。
- 电脑关掉：投影页横幅 + 自动重连；吊销则引导重配对。
- 审批条跨网可用。
- iPhone 加主屏能收到「需要你处理」并落到该会话。
- 规格正文不再把 Pier 默认写成「会合 + 账号」。
- 仓库中无「下一步改直连 / WebRTC」的 M2 待办。
