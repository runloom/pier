## 验收边界

- 进程退出、面板关闭独立；停止只发送原生进程组信号，2 秒升级，10 秒内等真实退出。终端与 scrollback 留存。
- 所有输入、延迟 Return、关闭、重启、窗口转移按实际 spawn 身份隔离。发送确认仅表示传输接受，不推断模型状态。
- 35 个智能体的首条任务能力进入现有 catalog；验证过的交互式原生参数携带任务，其余保存到增强输入框，手工提交。禁止计时粘贴任务到启动授权界面。
- 未发送草稿由 main 独立 JSON 原子持久化；发送前写检查点，歧义恢复为未确认；不自动重放，不存对话记录。
- 退出保留现有结果 UI，显式关闭等待资源清理；不存在的原生界面不伪装空屏成功。
- TaskRuns 停止请求等待真实子进程退出；现有普通 shell 关闭与任务成功语义保留。
- 四语文案、CLI 契约与手册同步；单测、静态检查、原生构建和隔离 E2E 验证。

## 验收中补齐的边界

- 原生进程组停止：真实 CLI fixture 证明交互 shell 包装会造成孙进程遗漏；最终 spawn 使用核验后的绝对路径与 `exec`，任务文本作为字面参数附加。
- 正常退出：销毁窗口后读取 `window.id` 会抛异常；提前捕获 ID，并由回归测试锁定。
- 草稿持久化：IPC schema 字段重排让 JSON 字符串比较误判编辑，形成无限保存；改为按完整内容生成稳定比较键。真实退出/重启用例验证恢复。
- 附件转移：完整异步操作先登记，再开始选择器/粘贴；旧保存 ACK 后无条件重新等待附件屏障。新用例在修复前复现提前 flush，修复后通过。
- 测试隔离：Electron 与 CLI 均使用独立 userData，清除继承的 Pier socket/面板/窗口身份；独立 ZDOTDIR/PATH 防止个人 shell 配置替换测试 CLI，避免本机测试连接正在使用的宿主。
- 原生显示初始化：独立 Swift 与本机 Electron 均复现 CoreVideo `-6661` 被误报为内存不足；0113 仅在显示服务不可用时使用已有按变化绘制路径。未修改产品默认 vsync，也未留下测试专用关闭配置。
